# Example

[`commuting-table/`](commuting-table/): a Czech record of a restricted statistical table, with a limitation on public access, use conditions and a funder.

- `item.json`: the record, in a simplified form of the JSON that DSpace's REST API returns (metadata values as plain strings).
- `export/`: its CCMM 1.1.0, INSPIRE (ISO 19139) and DataCite 4.6 records.

**This is a made-up record.** Its people, links (example.org) and DOI are invented. The DOI uses 10.5072, DataCite's old test prefix, retired in 2019, so it never resolves.
